# 🐾🤖 project_pet_link

[![GitHub Repository](https://img.shields.io/badge/GitHub-project__pet__link-181717?style=flat&logo=github)](https://github.com/sangrechy/project_pet_link)

**project_pet_link** was originally my idea of making an AI-powered robotic pet which can recognize me, follow me, interact with the surroundings and slowly behave more like an actual pet.

But currently, I haven't reached that stage yet.

What I actually have right now is basically a remote-controlled 4WD car with a camera attached to it, powered using a power bank.

---

## 🌟 What I'm Trying to Do

The original idea was to make a robot which can:

- **Follow the owner:** Use camera + sensors to detect and follow the owner.
- **Have its own behaviour:** Change how it reacts, follows and moves.
- **See things:** Use the camera to understand what is happening around it.
- **Move and react:** Control the robot and camera based on what it sees.
- **Talk/interact:** Later add voice interaction and make it behave more like a pet.

---

## 🛠️ What I Actually Built

For now, it is basically a 4WD remote-controlled car with a camera, powered by a power bank:

- **Dual ESP32 setup** with camera streaming and remote control.
- **2-axis Pan/Tilt camera**.
- **Python-based web control interface**.
- **Manual 4WD control**.

The hardware is still messy and experimental, so I wouldn't really call this a proper prototype yet. It's more like my first working attempt at the original idea.
